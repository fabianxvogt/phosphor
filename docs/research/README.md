Fractal flames combine nonlinear iterated function systems with density rendering and structural coloring ([Draves and Reckase](https://flam3.com/flame_draves.pdf)). CPPNs compose coordinate functions into compact pattern-generating networks ([Stanley, 2007](https://gwern.net/doc/ai/nn/fully-connected/2007-stanley.pdf)). Hyperbolic reflections must use a validated fundamental chamber, not decorative Euclidean warping ([Trettel's disk polygons](https://stevejtrettel.site/notes/2026/regular-polygons-disk-model/)).

Physarum-like particle chemotaxis can form persistent, adapting transport networks ([Jones](https://arxiv.org/abs/1503.06579)). Lenia supports diverse continuous cellular-automaton patterns, with evolutionary discovery reported by its author ([Chan](https://arxiv.org/abs/1812.05433)). Neither is already implemented by Phosphor's simple aquarium or Gray–Scott field.

Quaternion Julia slices are a strong later GPU project: genuine four-dimensional fractal iteration with a moving slice, lighting and bounded ray marching. Begin with a standalone shader benchmark before promising live high-resolution output. The current 4D geometry scene does not implement quaternion iteration.

## Implemented foundation

The studio update adds bounded Julia iteration with smooth escape/orbit-trap color, norm-preserving XW/YZ rotations of a tesseract, stereographic Hopf fibers with singularity handling, and Poincaré geodesics transformed by Möbius disk isometries. Tests verify geometric invariants and bounded drawing. Hyperbolic Loom is a curve instrument, not a regular tiling. Evolution Garden remains human-selected scalar mutation of harmonic contours.

Four composable effects provide immediate artistic range without pretending to be new simulation mechanisms. Next mixing should use two independent bounded scene buffers with opacity/blend control, measured frame cost, and versioned saves. Avoid arbitrary unbounded scene graphs.

## Music direction

Current implementation uses local files, a synthetic pulse, microphone and optional user-selected tab audio. Browser audio-track availability must be checked; tab sharing requires user interaction and varies by browser ([Chrome screen-sharing controls](https://developer.chrome.com/docs/web-platform/screen-sharing-controls)). Captured tab/microphone audio is analysed locally, never monitored or included in exported recordings.

Use official radio player links for discovery, including [cliqhop IDM](https://somafm.com/cliqhop/). Do not bundle its raw endpoints: SomaFM describes direct links as personal-use only and excludes games/streams ([direct-stream terms](https://somafm.com/live/directstreamlinks.html)). Cross-origin audio analysis requires suitable CORS permission ([Web Audio specification](https://www.w3.org/TR/webaudio-1.0/#MediaElementAudioSourceNode-security)); ordinary audible playback does not establish analyser access. A custom URL or station directory is deferred.

Prefer future music mapping to low/mid/high energy, onset envelopes, color, camera drift and bounded deformation. Keep silence calm and use stable smoothing. Current smoothed-energy response is not beat/BPM detection.
